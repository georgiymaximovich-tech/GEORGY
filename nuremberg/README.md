# Нюрнбергский процесс: обвинение на «суде народов»

Доклад по прокурорскому надзору, тема «Участие прокурора в рассмотрении уголовных дел судами».
Докладчики: Егоров Г. (слайды 1–9), Халимбеков А. М. (слайды 10–19).

## Готовые файлы

| Файл | Что это |
|---|---|
| `Нюрнберг.pptx` | Презентация PowerPoint, 19 слайдов. Справа на каждом слайде видео в стиле «рилс»: оно запускается само, без звука и по кругу, на каждом слайде с нового места. Текст выступления лежит в заметках к слайдам. Нужен PowerPoint 2013 или новее. |
| `Нюрнберг.html` | HTML-версия одним файлом: шрифты и видео уже внутри, интернет не нужен. |
| `index.html` | Исходник HTML-версии, берёт видео из `media/`, шрифты из `fonts/`. |
| `текст-доклада.md` | Текст выступления по слайдам с разделением по докладчикам. |

Слайды в PowerPoint вставлены картинками, текст на них не редактируется. Чтобы что-то поправить, измените `index.html` и пересоберите (см. ниже).

## Видеоряд

Четыре «залипательных» 3D-ролика 720×1280, по одному на каждый блок доклада:

| Ролик | Слайды | Что происходит |
|---|---|---|
| `media/press.mp4` | 1–5 | Гидравлический пресс плющит разноцветные шары пластилина в лепёшки, скребок их сдвигает |
| `media/sand.mp4` | 6–9 | Нож режет слоёный кинетический песок, ломтики падают узором вверх и уезжают по ленте |
| `media/tiles.mp4` | 10–14 | Поле плиток синхронно переворачивается волнами: кругом, спиралью, диагональю |
| `media/wave.mp4` | 15–19 | «Волна маятников»: 15 маятников рисуют змейки и ровно через 30 секунд снова выстраиваются в линию (бесшовная петля) |

Поверх видео нарисован интерфейс ленты: подпись к «посту» меняется на каждом слайде.
Ролики собраны процедурно на three.js, без чужих видеофайлов: `tools/satisfying3d/scenes.js`.

## Показ HTML-версии

Откройте `Нюрнберг.html` в Chrome, Edge или Firefox.

| Клавиша | Действие |
|---|---|
| → / Пробел / PageDown | следующий слайд |
| ← / PageUp | предыдущий слайд |
| F | полный экран |
| V | скрыть или показать колонку с видео |

## Пересборка

```bash
cd nuremberg/tools
# видео (покадровый рендер в headless Chromium; нужен ffmpeg)
node render.mjs press 40 ../media/press.mp4      # аналогично sand 40, tiles 40, wave 30
# снимки слайдов и PowerPoint
node shots.mjs /tmp/shots
python3 build_pptx.py /tmp/shots ../Нюрнберг.pptx
python3 build_single.py ../Нюрнберг.html
```

Сцену можно посмотреть вживую через локальный сервер из корня репозитория:
`python3 -m http.server` и `http://localhost:8000/nuremberg/tools/satisfying3d/?scene=sand`.
