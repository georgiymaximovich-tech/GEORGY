# Презентация: прокурор в сфере дознания и предварительного следствия

Доклад: Егоров Г., Халимбеков А.

## Как запустить

Откройте `index.html` в браузере (Chrome, Edge, Firefox). Интернет не обязателен: без него будут системные шрифты.

| Клавиша | Действие |
|---|---|
| → / Пробел / PageDown | следующий слайд |
| ← / PageUp | предыдущий слайд |
| F | полный экран |
| V | скрыть или показать колонку с геймплеем |

Кликер для презентаций тоже работает, он отправляет PageUp/PageDown.

## Геймплей справа

На каждом слайде справа идёт непрерывный вертикальный «раннер» в духе Subway Surfers. Это собственная анимация на canvas: она работает без интернета и без чужих видеофайлов и не перезапускается при смене слайда.

Чтобы вместо неё показывать настоящую запись геймплея:

- положите видеофайл в `media/gameplay.mp4`, и он подхватится автоматически (без звука, по кругу, с обрезкой под 9:16);
- или прямо во время показа перетащите видеофайл мышью в окно презентации.

## Файлы

- `index.html` — презентация (14 слайдов).
- `текст-доклада.md` — текст выступления по слайдам с разделением по докладчикам.
